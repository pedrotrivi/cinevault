# CineVault 2

Personal desktop media catalog and library manager for organizing movies and TV shows, tracking watch history, and syncing personal watchlists.

## Trakt Notice
CineVault 2 uses Trakt but is not endorsed or certified by Trakt.

## Privacy
CineVault 2 stores authentication tokens and watch progress locally and in the user's personal database. No user data is shared with or sold to third parties.
